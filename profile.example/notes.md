# Notes

Free-form background, written by /setup from whatever doesn't fit the structured fields
in `career.json`, `threads.json`, `evidence.json` or `market.json`: side interests,
context on a gap in the timeline, an unusual combination of skills, why you're looking
now, anything that would help a thoughtful reader understand the whole picture.

This file is context for reasoning, **never a source for a claim**. Hard rule 2 still
applies in full: a line on a CV, letter or form answer must trace to `career.json`,
`evidence.json`, or something confirmed in the current conversation. Nothing here
satisfies that test by itself. If something here would strengthen an application, it
gets confirmed and written into the right structured file first — the same way any other
fact does — not quoted from here directly.

There is nothing to fill in here until /setup asks. Replace this paragraph with your own
notes then; delete whatever doesn't apply.
